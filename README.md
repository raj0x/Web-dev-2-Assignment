# Lab 2 — Personal Portfolio Website (CSS Core)

## Files
- `index.html` — semantic HTML structure for About, Skills, Projects, and Contact.
- `style.css` — all styling is kept in an external stylesheet, as required by the lab.
- `images/profile.jpg` — your uploaded profile photograph.

## Run
1. Keep `index.html`, `style.css`, and the `images` folder together.
2. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.
3. Internet access is needed for the Google Font; the page falls back to Arial if it is unavailable.

## Notes
The contact form is a front-end demo: it validates the fields and displays a message, but does not send email without a backend.
